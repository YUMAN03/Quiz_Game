# Quiz Game

Welcome to the Quiz Game! This is a fun quiz application based on Greek mythology, developed by Yuman and Yashasvi.

## Introduction
The Quiz Game is an interactive web application that tests your knowledge of Greek mythology. The quiz presents multiple-choice questions, and you can see your score as you progress.

## Features
- Multiple-choice questions about Greek mythology
- Randomized questions for each quiz session
- Score tracking
- Responsive design

## Installation
To run this project locally, follow these steps:

1. Clone the repository:
    bash
    git clone https://github.com/yashasviy/Quiz_Game.git
    

2. Navigate to the project directory:
    bash
    cd Quiz_Game
    

3. Open index.html in your web browser to start the game.

## Usage
1. Click the *Start* button to begin the quiz.
   ![image](https://github.com/user-attachments/assets/e14f5e34-82f9-44e0-8dc7-536856f10307)

2. Answer the questions by clicking on the buttons with the possible answers.
3. Your score will be updated based on correct answers.
   ![image](https://github.com/user-attachments/assets/d3c93af3-ef46-4f8f-9700-b88e070e93a9)

4. Click the *Next* button to proceed to the next question.
   ![image](https://github.com/user-attachments/assets/84427f33-9b4f-47c1-af1e-748fa9fa7b41)

5. At the end of the quiz, you can restart by clicking the *Restart* button.
